#Green Club — VK-бот для оформления заказов
##Green Club — чат-бот для сообщества ВКонтакте, который помогает гостям ресторана самостоятельно выбирать блюда и напитки, настраивать позиции заказа и отправлять сформированный заказ администратору.

Бот реализован на Python с использованием vkbottle. Меню и цены хранятся в отдельном JSON-файле, поэтому для изменения ассортимента не требуется править основную логику приложения.
Возможности
- Интерактивное меню с разделами «Кухня», «Бар», «Кальяны» и «Дополнительно».
- Категории и навигация с кнопками ВКонтакте, включая постраничный просмотр категорий бара.
- Выбор варианта позиции: объём напитка или вариант добавки, если они предусмотрены в меню.
- Персонализация заказа:
  - выбор остроты бургера;
  - пожелания к сладости или кислотности отдельных напитков;
  - выбор вкусовой группы, крепости и дополнительных пожеланий для кальяна.
- Корзина с отображением состава и общей стоимости заказа, удалением последней позиции и полной очисткой.
- Оформление заказа: указание номера беседки (от 1 до 8), комментария и способа оплаты.
- Способы оплаты: картой при обслуживании, наличными или переводом по указанным реквизитам.
- Отправка заказа администратору в личные сообщения ВКонтакте; при выборе перевода к заказу прикладывается присланный пользователем скриншот.
Бот не проводит платежи и не проверяет их поступление автоматически. Скриншот перевода используется только для последующей проверки сотрудником.

##Технологии
Компонент	Назначение
Python	Логика бота и обработка сообщений
vkbottle	Взаимодействие с VK API, обработчики сообщений и клавиатуры

##Структура проекта
Green-Club-VK-Bot/
├── bot.py         # Основная логика бота
├── menu.json      # Категории, позиции, цены, объёмы и варианты
├── config.json    # Токен сообщества и VK ID администратора (не публиковать)
└── README.md      # Документация
В приложенных к проекту файлах основной скрипт называется BOT_V1 (1).py, а меню — menu (1).json. Перед запуском переименуйте их в bot.py и menu.json: именно menu.json скрипт загружает по имени.
##Установка и запуск
1. Подготовьте окружение. Понадобятся Python и сообщество ВКонтакте с подключёнными сообщениями и токеном доступа, позволяющим боту работать с сообщениями.

2. Скачайте файлы проекта в одну папку и приведите названия к структуре выше.

3. Создайте виртуальное окружение (рекомендуется).

Windows (PowerShell):
py -m venv .venv
.\.venv\Scripts\Activate.ps1
Linux / macOS:
python3 -m venv .venv
source .venv/bin/activate
4. Установите зависимость:
python -m pip install vkbottle
5. Настройте config.json:
{
  "vk_token": "YOUR_VK_GROUP_TOKEN",
  "admin_id": 123456789
}
- vk_token — токен доступа сообщества ВКонтакте.
- admin_id — числовой VK ID пользователя, которому отправляются заказы. Убедитесь, что сообщество может отправлять ему сообщения.
6. Запустите бота:
python bot.py
Для работы бот должен оставаться запущенным. После запуска откройте сообщения сообщества и отправьте «Начать» или «Старт».
Как пользоваться
1. Гость открывает диалог с сообществом и отправляет «Начать».
2. Выбирает раздел меню и категорию, затем отправляет номер интересующей позиции в пределах открытой категории.
3. При необходимости уточняет объём, вариант или пожелания к позиции.
4. Переходит в «Корзину», проверяет состав и сумму заказа.
5. Нажимает «Оформить заказ», указывает номер беседки и комментарий.
6. Выбирает способ оплаты. Для перевода бот показывает реквизиты и запрашивает фото подтверждения.
7. Бот формирует сообщение с составом заказа, суммой, номером беседки и способом оплаты и отправляет его администратору.
После успешной отправки заказа корзина и данные текущего заказа пользователя очищаются.
Настройка меню
Все позиции хранятся в menu.json. Файл содержит четыре раздела:
- kitchen_categories — категории кухни;
- bar_categories — категории бара;
- hookah_menu — кальяны;
- extras_menu — дополнительные услуги.
Пример позиции в категории кухни:
{
  "pizza": {
    "name": "🍕 Пицца",
    "items": {
      "101": {"name": "4 сыра", "price": 1100},
      "102": {"name": "Маргарита", "price": 650}
    }
  }
}
Этот фрагмент представляет содержимое поля kitchen_categories, а не полный menu.json.

Для позиций с несколькими объёмами используются поля volumes и строка с ценами через /, например:
{
  "name": "Капучино",
  "price": "350/450",
  "volumes": ["200 мл", "350 мл"]
}
Для выбора разновидности позиции предусмотрено поле variants. Дополнительные вопросы (острота, крепость и т. д.) определяются в коде для конкретных товаров и категорий. Изменения в menu.json применяются после перезапуска бота.
Как устроена логика
- Обработчики @bot.on.message реагируют на команды и текстовые сообщения пользователей.
- Клавиатуры Keyboard обеспечивают выбор разделов, категорий и вариантов заказа.
- user_data хранит корзину, выбранную категорию и этап оформления отдельно для каждого пользователя.
- new_user_state() создаёт начальное состояние пользователя.
- MODIFIER_STEPS описывает последовательность дополнительных вопросов к позициям.
- build_order_text() формирует итоговое сообщение для администратора.
- send_order_to_admin() отправляет заказ через VK API.
Программа работает как один Python-скрипт; отдельная база данных и веб-сервер в текущей реализации не используются.
Ограничения текущей версии
- Хранение данных в оперативной памяти: корзины и этапы оформления сбрасываются при перезапуске процесса. Постоянной базы заказов нет.
- Нет автоматического подтверждения оплаты: перевод и присланный скриншот требуют ручной проверки.
- Фиксированный диапазон беседок: доступны номера с 1 по 8; он задан в VALID_GAZEBO_NUMBERS.
- Реквизиты перевода заданы в исходном коде: перед реальным использованием необходимо заменить тестовые значения в TRANSFER_REQUISITES.
- В исходном menu.json есть повторяющиеся коды 230 и 245 в разных категориях бара. Поскольку бот объединяет товары в один словарь по коду, эти совпадения могут привести к добавлению неверной позиции. Перед использованием назначьте каждому товару уникальный код.
- Неодинаковое название заведения в сообщениях: в некоторых текстах используется Green Club, в других — Green Lounge. При адаптации проекта стоит привести название к одному варианту.

Назначение проекта: автоматизация приёма заказов через сообщения сообщества ВКонтакте и сокращение числа ручных действий при передаче заказа сотруднику заведения.
